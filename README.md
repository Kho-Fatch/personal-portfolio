## Purpose of the Website

This website is my personal portfolio and online professional identity. It introduces who I am, shows my education and technical skills, presents my software projects with links to their GitHub repositories, and demonstrates several animated web concepts built with HTML, CSS and JavaScript.

## Projects Showcased

1. **Radio Tracker:** helps a radio station track events, updates and activities. Built with Python, FastAPI and Next.js.
2. **ERP System:** assigns work to users and collects their feedback on tasks. Built with Python, FastAPI and Next.js.
3. **Borehole Risk Prediction System:** uses a risk score to predict which boreholes are more likely to fail. Built with Python and Flask.

## Animated Concepts Implemented

1. **Typing animation:** text is typed and deleted automatically (JavaScript).
2. **Animated skill bars:** bars fill when scrolled into view (CSS transitions).
3. **Animated shapes and background:** floating shapes and a moving gradient hero background (CSS keyframes).
4. **Hover effects:** navigation links, buttons, project cards and skill cards react to the mouse (CSS transitions and transforms).
5. **Scroll reveal:** content fades in as the visitor scrolls (JavaScript Intersection Observer).

## Technologies Used

- **HTML5:** page structure, tables, lists, images, hyperlinks and `mailto:` links
- **CSS3:** external stylesheet, Flexbox, CSS Grid, transitions, keyframe animations and responsive layout using media queries
- **JavaScript:** typing effect and scroll animations
- **Visual Studio Code** with the Live Server extension for development
- **Git and GitHub Pages** for hosting

## How to Run Locally

1. Download or clone the repository.
2. Open the `PersonalPortfolio` folder in Visual Studio Code.
3. Install the **Live Server** extension.
4. Open `index.html` and click **Go Live**, or simply open `index.html` in a web browser.

## Responsive Design

The website adapts to phones, tablets and desktop computers using flexible layouts (Flexbox and Grid) and CSS media queries.
